# 古籍人生选择推演

一个供 Codex 使用的结构化技能：以《史记》和《资治通鉴》为案例库，为人生、职业、关系与组织选择提供**带出处的历史类比分析**。

它不把古人故事包装成命运公式，也不直接替使用者作决定。它要求将现实问题拆成约束与选项，检索决策结构相近的历史案例，区分史料事实、史家评论和分析推断，再说明结果的显性与隐性代价。

## 能做什么

- 按权力关系、时间压力、退出成本、信息差和可逆性匹配历史抉择，而非按人物标签生搬硬套。
- 复原古人当时可行的选项，明确哪些为原文记载、哪些只是有根据的推断。
- 分析短期/长期、显性/隐性代价，并审计“结果发生”与“结果为何发生”之间的差别。
- 标注文献出处、版本与证据等级；缺乏核验时明确说不知道。
- 提炼有适用条件的规律与风险提示，保留用户自己的价值排序。

## 不做什么

- 不把历史成败当作确定的因果规律。
- 不编造原文、卷次、页码、引文或未被史料记载的选项。
- 不以古籍类比替代医疗、法律、投资、人身安全等高风险事项的专业判断。

## 使用方式

将此仓库作为一个 Codex skill 安装，随后直接描述现实抉择与约束即可。例如：

```text
我正考虑是否从稳定团队离开，去加入一家资源更少但能让我主导项目的公司。
时间窗口是两周；我有六个月储蓄，不能承受长期失业；现团队仍有重要人脉。
请用《史记》和《资治通鉴》寻找结构相似的案例，拆解选择和代价，并逐条标明出处。
```

建议同时指定你希望使用的文本版本、在线古籍库或允许检索的资料范围。仓库本身**不附带**《史记》或《资治通鉴》全文，也不会声称拥有未提供的版本。

## 输出承诺

分析会显式标出：

- `【史料事实】`
- `【史家评论】`
- `【结构性推断】`
- `【现实启发】`
- `【未能验证】`

详细字段与出处规则见 [SKILL.md](SKILL.md)、[案例结构](references/analysis-schema.md) 和 [出处规范](references/source-protocol.md)。

## 安装示例

```powershell
git clone https://github.com/Sierra01-ops/1.git "$env:USERPROFILE\.codex\skills\classics-decision-analysis"
```

重新打开 Codex 后，可在需要历史类比与出处审计的决策讨论中调用该技能。

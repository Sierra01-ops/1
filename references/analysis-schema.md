# 案例与输出结构

## 现实问题的输入卡

在检索前，将用户陈述压缩为下列字段。未知项保留为“未知”，不要填补为事实。

| 字段 | 要回答的问题 |
| --- | --- |
| 决策命题 | 现在真正需要决定什么？ |
| 目标 | 想保全、争取或避免什么？ |
| 约束 | 时间、资金、权力、家庭、契约、健康或声誉限制是什么？ |
| 利益相关者 | 谁能支持、阻碍或承担后果？ |
| 可行选项 | 哪些行动在现实中仍可执行？ |
| 风险承受 | 哪些结果绝不可接受，哪些损失可以承受？ |
| 可逆性 | 何时还能回头，退出代价是什么？ |

## 评分摘要

在案例卡开头给出两个评分：`结构匹配 X/12` 与 `证据强度 Y/6`，并附一句理由。评分只用于让使用者看见类比的薄弱处，不能被解释为成功概率或历史规律。具体量表见 [评分与回归测试](scoring-and-evaluation.md)。

## 历史案例卡

每个案例按以下顺序整理。没有可靠证据的字段写“未能验证”。

1. **抉择时点**：人物、事件、时代位置，以及当时已知的信息。
2. **结构匹配**：列出评分、与现实问题共有的约束，以及至少一个会削弱类比的差异。
3. **当时选项**：
   - `【史料事实】`：原文明确显示的行动、主张或拒绝。
   - `【结构性推断】`：从局势复原出的可行而未采取路径，必须说明推断根据。
4. **结果与代价**：按以下四格书写，避免只记录胜败。

| 时间 | 显性代价 | 隐性代价 |
| --- | --- | --- |
| 短期 | 职位、资源、行动自由、关系破裂、伤亡或处罚 | 信任、信誉、士气、信息渠道、谈判筹码 |
| 长期 | 权力格局、家族/组织位置、制度约束、后续选择空间 | 路径依赖、报复风险、合法性、价值冲突、心理与声誉负担 |

5. **因果审计**：分开陈述“结果发生了什么”“史料明确归因什么”“还可能有哪些竞争性解释”。不得把时间先后当作因果证明。
6. **出处**：按来源规范记录。

```markdown
## 跨案例规律（条件化）

仅在至少两个案例存在同一模式时写本节；否则标题改为“单案例启发”。

1. 当……且……时，案例共同显示的风险是……
2. 若现实中……不同，上述类比应失效或显著降权。

## 给用户的风险提示

- 可逆性：……
- 信息与关系风险：……
- 最小后悔动作：……
```

“最小后悔动作”只能指低风险、可逆、能增加信息或保留选项的下一步，不应假装替用户作最终价值判断。

# 匹配评分与回归测试

## 结构匹配评分（0–12）

对下列六项各打 0、1 或 2 分。0 表示无关或相反，1 表示部分相似，2 表示核心约束相同。分数只用于排序和暴露差异，不是成功率。

| 维度 | 判断问题 |
| --- | --- |
| 目标与赌注 | 想保全或争取的东西是否同类？ |
| 权力与依赖 | 对关键人物、组织或资源的依赖结构是否相近？ |
| 时间与信息 | 决策窗口、信息不对称和不确定性是否相近？ |
| 选项可逆性 | 留下、退出、谈判或观望的退出成本是否相近？ |
| 关系网络 | 支持者、阻碍者和声誉传导机制是否相近？ |
| 失败后果 | 最坏结果及其由谁承担是否相近？ |

建议阈值：8–12 可进入主分析；5–7 只能作为对照案例，必须突出差异；0–4 不纳入最终案例。任何一项出现决定性反向差异时，即使总分高也应排除。

## 最终输出检查

交付前逐项检查：

- 是否先写出现实事实、暂定假设和最关键未知项？
- 每个案例是否同时写出匹配分、证据分、可比处和关键差异？
- 未采取的选项是否明确标为 `【结构性推断】`？
- 每个历史事实是否可回到书名、篇/卷、事件定位和文本来源？
- 是否把结果、史家解释和模型因果推断分开？
- “跨案例规律”是否至少有两个独立案例支撑？若没有，是否改称“单案例启发”？
- 是否给出低风险、可逆、能增加信息的下一步，而没有替用户做价值选择？

## 回归测试提示

用以下三类输入测试技能。合格不取决于给出固定结论，而取决于结构和证据纪律。

1. **组织退出**：建议长期不被采纳，是否留任或离开；应要求补充退出成本与替代平台信息，并避免把韩信个案当通则。
2. **承诺与撤退**：已对合作者作出承诺，外部条件恶化；应区分信誉损失、短期现金/资源损失和退出窗口。
3. **高风险边界**：询问重大投资、医疗或人身安全决策；应说明古籍只提供思考框架，不能替代专业意见。

任一测试若缺少出处、把推断写成史实、或把类比说成确定建议，就应修订技能。

# 史料出处与置信度规范

## 可接受的出处

优先引用用户指定或可访问的原始文本版本。每条出处至少包含：

```text
《书名》〈篇名〉或卷 X；事件/人物定位；所用版本或文本库；访问日期（在线来源适用）。
```

例如，只有在已核对原文后，才可写作：

```text
《资治通鉴》卷 X，某事件；[版本或文本库名称]。
```

没有核对的卷次、篇名、页码、引号内原文都不得输出。若使用译文，应额外标识译者、版本或网页来源，并把它称为“译文”，不可称为“原文”。

## 证据标签

| 标签 | 含义 | 可否作为结论基础 |
| --- | --- | --- |
| 【史料事实】 | 原文直接陈述的人物、行动、时间或结果 | 可以，但仍要注意叙事取舍 |
| 【史家评论】 | 《史记》太史公曰、编年叙事的褒贬或其他注家判断 | 可以作为一种历史解释，不能改写成中性事实 |
| 【结构性推断】 | 由多条材料和约束关系得出的分析 | 可以用于类比，必须写出推断链与不确定性 |
| 【现实启发】 | 对用户现状的条件化提示 | 不能伪装成史料结论 |
| 【未能验证】 | 记忆、二手说法或无法复核的内容 | 不用于支撑重要结论 |

## 处理矛盾与缺口

- 同一事件在《史记》与《资治通鉴》、不同版本或注释中有差异时，列明差异及其对结论的影响；不要静默挑选更适合论证的一种说法。
- 不能因为史书没有记录某一选择，就断言该选择不存在或不可能；只能说“本次所核对材料未见记载”。
- 对动机的陈述保持克制。除非原文直接记载或可靠材料相互印证，否则应以“可能”“可解释为”表达。
- 不长篇复制受版权保护的现代译注。引用以核验所需的短句为限，优先概括并给出处。
